# Profile README development notes

- `README.md` wires the five SVG assets into the GitHub profile.
- `assets/hero.svg` is the banner and stylized generic character.
- `assets/about-life.svg` introduces the developer and interests.
- `assets/stack.svg` lists a selection of technologies.
- `assets/id-dashboard.svg` is a compact developer identity panel.
- `assets/connect.svg` contains a GitHub link and a placeholder for LinkedIn.

SVGs are self-contained, use local vector shapes and text, and make no external asset requests. No JavaScript or external font is required. Update project links and social URLs as they are confirmed.
